# 决策 0001：不使用 AE350 硬核

- 日期：2026-11-25
- 状态：已定

## 背景

GW5AST-138 内置 AE350 RISC-V 硬核。用它跑 Linux 会容易得多，但项目性质会变。

## 决策

**不使用 AE350 硬核**，CPU 一律用 VexRiscv 软核（RV32IMAC + Sv32 MMU + I/D Cache）。

## 理由

1. 项目要展示的是「手写 AXI 总线 + SoC 集成」，用硬核之后 CPU 部分变成厂商黑盒配外设，和题意不符。
2. 面试时会被追问「你的 CPU 是自己写的还是硬核」，用硬核等于主动放弃这一块。
3. 硬核与自研总线之间的接口由厂商定义，绕开了本项目最想练的部分。

## 影响

- 资源上更宽裕，但不需要因此扩大范围（见决策 0002）。
- 若将来只想快速验证外设，可以临时用硬核做对照实验，但不得进入主交付物。
