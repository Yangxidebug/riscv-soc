# 决策 0002：DDR3 位宽与 AXI 数据宽

- 日期：2026-11-25
- 状态：已定

## 事实

板载 DDR3 为单颗 16 位颗粒，256 MB：

| 信号 | 数量 |
| --- | --- |
| DQ | 16 |
| DQS 差分对 | 2 组 |
| DQM | 2 |
| 行地址 | 14 |
| 列地址 | 10 |
| Bank | 3 |

容量 = 2^14 × 2^10 × 2^3 × 2 B = 256 MB，与厂家标注一致。

## 决策

- DDR3 控制器使用 **1:4 时钟比**
- 用户接口数据宽 **128 位**（= 16 × 8）
- CPU 侧为 32 位，因此需要 **128 → 32 的窄化层**

## 理由

1. 位宽由 `Dq Width × 8`（1:4 时）决定，16 位颗粒只能是 128 位，没有选择余地。
2. 128 位 @ 1100 Mbps 约 2.2 GB/s，带宽远超单核需求；换成 1:2 只能得到 64 位且突发效率下降，不划算。

## 影响

- 交叉矩阵与 DDR 之间的写路径需要处理写选通（`WSTRB`）到字节掩码（`DQM`）的映射。
- 窄化层是继交叉矩阵之后的第二个核心模块。
- 三个独立来源印证同一结论：通用管脚分配表、第 38 章例程的约束文件、Gowin DDR3 IP 的参数窗口。
