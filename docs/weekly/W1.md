### DDR3 位宽的三层关系（待确认最后一步）

| 概念 | 含义 | 本板取值 |
| --- | --- | --- |
| Dram Width | 单颗颗粒自身的位宽 | x8 或 x16 |
| Dq Width | 控制器接口总位宽 = 颗粒数 × Dram Width | 单颗，故只能是 8 或 16 |
| AXI Data Width | 1:4 时 = Dq × 8；1:2 时 = Dq × 4 | 见下表 |

| Dram Width | Dq | 1:4 时钟比 | 1:2 时钟比 | 峰值带宽（1:4） |
| --- | --- | --- | --- | --- |
| x16 | 16 | 128 位 | 64 位 | 约 2.2 GB/s |
| x8 | 8 | 64 位 | 32 位 | 约 1.1 GB/s |

确认方法：看 Sipeed 官网原理图上 DDR3 的型号，`256M16` 是 x16，`512M8` 是 x8。
