## 二、本周笔记与关键结论

四篇笔记基于 HDLBits 到 FSM 阶段的错题整理，均用 ModelSim SE-64 10.6e 逐拍仿真验证（`Errors: 0`）。原文存放在本地 `note/` 目录，属于通用理论积累，不纳入本仓库。每篇最硬的一条结论摘录如下。

| 编号 | 主题 | 最硬的一条结论 |
| --- | --- | --- |
| 01 | 异步 FIFO | 格雷码判满要比较最高**两位**相反、其余位相同；只比一位是错的，用 101 检测同款方法可验 |
| 02 | FSM 三种输出模型 | 同一激励下 Moore 与寄存 Mealy 的输出都晚命中拍一拍，只有组合 Mealy 同拍 |
| 03 | Moore / Mealy 序列检测复盘 | 移位寄存器检测天然滞后一拍，拿它当定时链的启动基准会让整条链错位 |
| 04 | Fancytimer 五坑 | 五个坑的根子相同：没搞清某个值在哪个时钟沿之后才有效 |

## 三、踩坑记录

| 坑 | 现象 | 处理 |
| --- | --- | --- |
| 文件末尾缺换行 | `EOFNEWLINE` 警告终止编译 | 补换行 |
| `--binary` 自动加 main | `multiple definition of main` | 改用 `--cc --exe --build` |
| `--Mdir` 父目录不存在 | `Cannot write .../Vcounter__Syms.cpp` | Makefile 里先 `mkdir -p` |
| `--Mdir` 移出当前目录 | 源码相对路径失效 | RTL 与 TB 一律用绝对路径 |

## 附录 A：DDR3 位宽三层关系（寒假 W3 用）

| 概念 | 含义 | 本板取值 |
| --- | --- | --- |
| Dram Width | 单颗颗粒自身的位宽 | x8 或 x16 |
| Dq Width | 控制器接口总位宽 = 颗粒数 × Dram Width | 单颗，故只能是 8 或 16 |
| AXI Data Width | 1:4 时 = Dq × 8；1:2 时 = Dq × 4 | 见下表 |

| Dram Width | Dq | 1:4 时钟比 | 1:2 时钟比 | 峰值带宽（1:4） |
| --- | --- | --- | --- | --- |
| x16 | 16 | 128 位 | 64 位 | 约 2.2 GB/s |
| x8 | 8 | 64 位 | 32 位 | 约 1.1 GB/s |

确认方法：看 Sipeed 官网原理图上 DDR3 的型号，`256M16` 是 x16，`512M8` 是 x8。
